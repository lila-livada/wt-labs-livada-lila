# Labor 1 – Überprüfen Sie Ihr Verständnis

Zeit: 5 Minuten. Beantworten Sie die Fragen, ohne in Ihre Notizen zu schauen.

**1.** Welches Element enthält den Inhalt, der auf der Seite sichtbar ist?

- a) `<head>`
- b) `<title>`
- c) `<body>`
- d) `<meta>`

**2.** Sie möchten denselben Stil auf fünf Listeneinträge anwenden und nur einem davon eine besondere Farbe geben. Welche Kombination ist geeignet?

- a) Fünf verschiedene IDs
- b) Eine Klasse für alle fünf, plus eine ID für den besonderen Eintrag
- c) Dieselbe ID für alle fünf
- d) Inline-Stile bei jedem Eintrag

**3.** Was ist an dieser Zeile falsch?

```html
<img src="images/logo.svg">
```

**4.** Schreiben Sie die CSS-Regel, die jedem Element mit der Klasse `subject` ein Padding von `1rem` gibt.

**5.** Welcher der beiden Werte ist in einer Box mit `margin: 10px; padding: 20px; border: 1px solid black;` der Abstand *zwischen dem Rahmen und dem Inhalt*?

**6.** Bringen Sie die Git-Befehle in die Reihenfolge, in der Sie sie nach dem Bearbeiten einer Datei verwenden: `git push`, `git commit -m "…"`, `git add .`
